# Disboard Docs

[![Netlify Status](https://api.netlify.com/api/v1/badges/b2f37b31-a4f7-479a-b9f9-204c9a07b194/deploy-status)](https://app.netlify.com/projects/disboard-docs/deploys)

Documentation that covers everything related to the disboard project

## Used

- Nodejs
- VitePress
- Netlify deploy/hosting - [site](https://www.netlify.com)

### Dependencies

- VitePress 1.6.4

## Setup

Run `npm install` to install all dependencies.

```shell
npm install
```

Start the VitePress development server:

```shell
npm run dev
```

Build the documentation:

```shell
npm run build
```

You will then be able to access it at localhost:5173
